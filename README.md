# EndfieldCombatHUD

[English](README_EN.md) | 中文

增强《明日方舟：终末地》的战斗 HUD，提供 Buff/Debuff 详情提示、连携技冷却和终结技充能显示。悬停状态图标即可查看持续时间、层数与属性变化。

## 下载

前置插件管理器：[Applepie Manager](https://github.com/zonemodAE/ApplepieManager)

您可以在 [Releases](https://github.com/Sasye/EndfieldBetterBuffBar/releases) 下载最新发布版或从源代码自行编译。

## 安装

先安装前置插件管理器：[Applepie Manager](https://github.com/zonemodAE/ApplepieManager)，再将以下文件复制到游戏目录（`Endfield.exe` 所在文件夹）：

```
bin/EndfieldCombatHUD.dll  → 游戏目录/plugin/EndfieldCombatHUD.dll
```

> 如果您**没有安装过此类型的插件**，您可能需要自行创建 `plugin` 文件夹。

## 使用方法

1. 按上述方式安装后启动游戏。
2. 进入战斗场景，待状态栏出现 buff/debuff 图标后，将鼠标悬停在对应图标上。
3. 悬停时会自动弹出该状态的属性详情面板。面板支持多分辨率动态缩放，适配 720p - 4K 屏幕。
4. 战斗中准星两侧会自动显示连携技 CD（左）和终结技充能（右），脱战或 UI 隐藏时自动隐藏。

Manager 显示 `Enabling` 时可点击“取消启用”；等待排空进入 `Disabled` 后可再次点击“启用”。已经启用时可用“停用”关闭 HUD。

## 基础配置

在 Manager 的插件设置中修改技能 HUD 快捷键、Buff HUD 快捷键、视觉增强和语言，修改后自动保存并生效。默认快捷键为 F11/F12，视觉增强关闭，语言为中文。点击当前键名后按下目标键，Esc 取消，清除可禁用该键。
